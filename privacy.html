VITA 개인정보처리방침

시행일: 2026년 11월 10일

VITA(이하 "앱")는 Wear OS 스마트워치용 앱으로, 음악·라디오 재생, 성경 읽기, AI 비서 기능을 제공합니다. 앱 개발자는 별도의 서버를 운영하지 않으며, 사용자의 개인정보를 수집·저장하지 않습니다. 이 방침은 앱이 기능을 제공하기 위해 어떤 정보를 어디로 보내는지 설명합니다.

1. 기능별 정보 처리

기능처리하는 정보와 전송 대상
AI 비서 (기본)시계에 내장된 Google Gemini를 열어 줍니다. 이때 앱은 음성을 녹음하거나 전송하지 않으며, 질문과 답변은 Google Gemini가 처리합니다(Google 개인정보처리방침).
AI 비서 (API 키 사용)사용자가 자신의 Gemini API 키를 넣은 경우, 녹음 버튼을 누른 동안의 음성을 Google Gemini API로 보내 답변을 받습니다. 녹음 파일은 답변을 받은 뒤 시계에서 바로 삭제됩니다. 음성은 해당 API 키의 Google 계정 약관에 따라 Google이 처리합니다(Gemini API 약관).
AI 답변 신고API 키로 받은 AI 답변이 틀리거나 부적절할 때 [신고]를 누르면, 그 답변 글과 AI 모델 이름만 중계 서비스(ntfy.sh)를 거쳐 개발자 이메일로 전달됩니다. 음성, 계정, 기기 정보는 보내지 않으며, 신고 내용은 앱 개선에만 사용합니다.
API 키 입력휴대폰 웹페이지에서 입력한 API 키는 휴대폰에서 암호화된 뒤 중계 서비스(ntfy.sh)를 거쳐 시계로 전달됩니다. 중계 서비스는 암호를 풀 수 없고, 메시지를 저장하지 않도록 설정되어 있습니다. 키는 시계 안에만 저장됩니다.
라디오선택한 방송사 서버에서 방송을 직접 받아 재생합니다. 방송사는 일반적인 인터넷 접속과 같이 접속 IP 등을 기록할 수 있습니다.
음악시계에 저장된 mp3 파일만 재생합니다. 앱이 음악을 스스로 내려받지 않으며, 재생 기록을 외부로 보내지 않습니다.
휴대폰에서 노래 보내기사용자가 직접 켠 동안에만, 같은 WiFi 안에서 휴대폰이 고른 mp3 파일을 시계로 바로 받습니다. 파일은 인터넷이나 다른 서버를 거치지 않고 시계에만 저장됩니다.
성경앱에 들어 있는 본문(성경전서 개역한글판 © 대한성서공회, 영어: King James Version)을 보여 주며, 외부로 정보를 보내지 않습니다.
앱 설정볼륨, 밝기, 마지막 곡, AI 모델 선택, 하루 질문 횟수 등은 시계 안에만 저장됩니다.

2. 권한

  • 마이크: API 키를 사용하는 AI 비서에서 질문을 녹음할 때만 사용합니다.
  • 오디오 파일 읽기: 시계의 음악 폴더에 있는 파일을 재생하기 위해 사용합니다.
  • 알림: 재생 중임을 시계 화면에 표시하기 위해 사용합니다.
  • 인터넷: 라디오, AI 비서, API 키 전달에 사용합니다.
  • WiFi 연결 요청: 휴대폰에서 노래를 받을 때 시계가 WiFi를 쓰도록 요청합니다.
  • 근처 기기(로컬 네트워크): "휴대폰에서 노래 받기"를 켤 때만, 같은 WiFi의 휴대폰이 시계로 노래 파일을 보낼 수 있도록 사용합니다. 위치를 확인하거나 다른 기기를 찾는 데에는 쓰지 않습니다.

3. 수집하지 않는 정보

앱은 광고, 사용 통계 분석, 위치 추적 기능이 없으며, 이름·연락처·계정 정보 등 개인을 식별할 수 있는 정보를 개발자에게 보내지 않습니다.

4. 정보 삭제

  • 시계에 저장된 API 키는 키 입력 페이지의 [시계의 키 지우기]로 지울 수 있습니다.
  • 앱을 삭제하면 시계에 저장된 설정과 API 키가 모두 삭제됩니다.

5. 아동

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.
